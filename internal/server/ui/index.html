Raft key-value store: live cluster

Three servers each hold a full copy of the data. One is elected leader and every write goes through it. A write only counts once a majority has saved it to disk. Disconnect any server and the rest elect a new leader in under a second (typically 0.3 s), with no data lost.

Try this

  1. Write a key. Watch it appear on every node.
  2. Disconnect the leader. The others hold an election.
  3. Write again. It still works, because the nodes that are left are still a majority.
  4. When the old leader reconnects, it steps down and catches up on what it missed.
